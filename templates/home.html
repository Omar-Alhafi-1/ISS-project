About This System

This secure e-voting system incorporates tamper-proof QR audit trails using salted SHA-256 hashing to ensure vote integrity and verification. Each vote can be independently verified by the voter without compromising ballot secrecy.

The system follows security standards from:

  • NIST SP 800-107 (Recommendations for Hash Functions)
  • ENISA Guidelines for secure e-voting systems
  • OWASP secure coding practices
