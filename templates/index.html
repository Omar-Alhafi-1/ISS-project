About Tamper-Proof QR Audit Trails

This system implements tamper-proof QR codes using salted SHA-256 hashing. Each QR code contains:

  • The original data you want to protect
  • A unique random salt to prevent rainbow table attacks
  • A SHA-256 hash of the data+salt combination

When verifying a QR code:

  1. The system extracts the original data, hash, and salt
  2. It recalculates the hash using the original data and salt
  3. It compares the stored hash with the calculated hash
  4. If they match, the data hasn't been tampered with

This implementation follows security standards from:

  • NIST SP 800-107 (Recommendations for Hash Functions)
  • ENISA Guidelines for secure e-voting systems
  • OWASP secure coding practices
